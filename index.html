Fondements du Machine Learning

Section 01

Concepts fondamentaux

Le machine learning est une branche de l'intelligence artificielle qui permet à une machine d'apprendre à partir de données sans être explicitement programmée pour chaque tâche. Au lieu de coder des règles à la main, on laisse la machine les inférer à partir d'exemples.

Définition formelle — Tom Mitchell (1998)

Définition officielleOn dit qu'un programme informatique apprend à partir d'une expérience E concernant une tâche T et une mesure de performance P, si ses performances sur T, mesurées par P, s'améliorent avec l'expérience E.
T — Tâche
Ce que le système doit accomplir : classer, prédire, jouer, filtrer...
E — Expérience
Les données sur lesquelles le système s'entraîne. Sans données, pas d'apprentissage.
P — Performance
Mesure objective. Doit être calculée sur de nouvelles données jamais vues.

Les trois types d'apprentissage

Supervisé — (X, y)
ŷ = f(x)
Données étiquetées. On apprend à prédire y à partir de x.

Exemples : prix, spam, diagnostic.
Non supervisé — (X)
clusters(X)
Pas de labels. La machine découvre des structures cachées.

Exemples : segmentation, compression.
Par renforcement — r(s,a)
max r
Apprentissage par récompense. L'agent interagit avec son environnement.

Exemples : AlphaGo, robots.

Supervisé — deux familles de problèmes

Régression

La sortie y est une valeur numérique continue.

ŷ ∈ ℝ → ex : 234.5 k€, 37.2°C
Classification

La sortie y est une catégorie discrète.

ŷ ∈ {0, 1, ...} → ex : spam, chat/chien

Régression Linéaire

Section 02

Le modèle linéaire ŷ = wx + b

La régression linéaire simple modélise la relation entre une variable d'entrée x et une variable de sortie y par une droite. C'est le modèle supervisé le plus fondamental.

Hypothèse — régression linéaire simpleŷ = w · x + b ŷ = prédiction du modèle (≠ y, la vraie valeur) x = variable d'entrée (ex : surface en m²) w = pente — variation de ŷ par unité de x b = biais — valeur de ŷ quand x = 0
Interprétation concrète

Si w = 2.5 et b = 40, pour une maison de 80 m² : ŷ = 2.5 × 80 + 40 = 240 k€. Chaque m² supplémentaire ajoute 2.5 k€ — c'est w, la "sensibilité" du prix à la surface.

Données d'exemple — 10 maisons

Section 03

La fonction de coût J(w, b)

Pour mesurer la qualité d'un modèle, on définit une fonction de coût J qui quantifie l'écart entre les prédictions ŷ et les valeurs réelles y. L'objectif est de trouver w et b qui minimisent J.

MSE — Mean Squared Error (avec convention 1/2m)J(w, b) = 1/(2m) · Σᵢ₌₁ᵐ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )² m = nombre d'exemples · le ½ simplifie les calculs de dérivées Convexité : J est une parabole → un seul minimum global → gradient converge toujours
Pourquoi l'erreur au carré, pas l'erreur absolue ?

L'erreur absolue |ŷ−y| n'est pas dérivable en 0, ce qui rend le gradient inutilisable. L'erreur au carré est dérivable partout, pénalise davantage les grandes erreurs, et produit une surface convexe avec un unique minimum global garanti.

Parabole J(w) — convexité visuelle

Section 04

Calcul des dérivées partielles

Pour descendre vers le minimum de J, il faut savoir dans quelle direction se déplacer. Le gradient — vecteur des dérivées partielles — donne cette information.

Démonstration de ∂J/∂w

1
Départ : J(w,b) = (1/2m) · Σᵢ (wx⁽ⁱ⁾ + b − y⁽ⁱ⁾)²
2
Poser uᵢ = wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ : J = (1/2m) · Σᵢ uᵢ²
3
Chain rule : ∂(uᵢ²)/∂w = 2uᵢ · ∂uᵢ/∂w ; or uᵢ = w·xᵢ + b − yᵢ → ∂uᵢ/∂w = xᵢ
4
Simplifier (le 2 se compense) : ∂J/∂w = (1/m) · Σᵢ (wx⁽ⁱ⁾ + b − y⁽ⁱ⁾) · x⁽ⁱ⁾

Résultats :
∂J/∂w = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · x⁽ⁱ⁾
∂J/∂b = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)

Calcul numérique — itération 0

Calcul numérique — w=0, b=0
Interprétation du signe du gradient∂J/∂w > 0 → J croît quand w augmente → il faut diminuer w ∂J/∂w < 0 → J décroît quand w augmente → il faut augmenter w ∂J/∂w = 0 → minimum atteint pour w → convergé ✓
Section 05

Algorithme de descente de gradient

La descente de gradient trouve w et b de façon itérative, en se déplaçant à chaque étape dans la direction qui fait baisser J le plus vite.

Analogie — descendre dans le brouillard

Imaginez-vous sur une colline dans le brouillard, cherchant la vallée. Vous ne voyez pas loin, mais vous sentez la pente sous vos pieds. Vous faites un petit pas dans la direction la plus raide vers le bas, et vous recommencez. En répétant cela, vous atteignez la vallée. C'est la descente de gradient.

Mise à jour SIMULTANÉE à chaque itérationw_new = w − α · ∂J/∂w = w − α · (1/m) · Σᵢ(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)·x⁽ⁱ⁾ b_new = b − α · ∂J/∂b = b − α · (1/m) · Σᵢ(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) w ← w_new ; b ← b_new (après avoir calculé les deux)
La simultanéité est obligatoire

On calcule les deux gradients avec les anciennes valeurs de w et b, puis on met à jour les deux ensemble. Mettre à jour w en premier et l'utiliser pour calculer le gradient de b produirait un algorithme incorrect — on minimiserait une autre fonction que J.

Impact de α — taux d'apprentissageα trop grand → le pas dépasse le minimum → J diverge α trop petit → convergence très lente (milliers d'itérations) α optimal → J décroît régulièrement et se stabilise Valeurs typiques à tester : 0.001 → 0.003 → 0.01 → 0.03 → 0.1 (×3 à chaque fois)

Section 06

Régression linéaire multiple

En pratique, plusieurs variables expliquent y ensemble. La régression multiple généralise le modèle à n variables d'entrée. La logique mathématique est exactement la même.

Modèle généralisé à n variablesŷ = θ₀ + θ₁·x₁ + θ₂·x₂ + … + θₙ·xₙ = θᵀx θ₀ = biais · θ₁…θₙ = poids · Total : n+1 paramètres Gradients : ∂J/∂θⱼ = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · xⱼ⁽ⁱ⁾ (j = 0…n, avec x₀ = 1)
Règle universelle

Pour tout paramètre θⱼ : ∂J/∂θⱼ = (1/m) · Σᵢ(erreur)·xⱼ. Cette structure est identique quel que soit n. Comprendre la régression simple suffit pour généraliser à n dimensions.

Section 07

Feature Scaling

Quand les variables ont des ordres de grandeur très différents, la descente de gradient converge lentement et de façon irrégulière. Le scaling est un prétraitement indispensable.

Normalisation min-max
x' = (x − min(x)) / (max(x) − min(x))
Résultat : x' ∈ [0, 1]
Sensible aux valeurs aberrantes
Standardisation (z-score)
x' = (x − μ) / σ
Résultat : moyenne=0, σ=1
Robuste aux outliers
μ et σ calculés sur train uniquement
Data leakage — erreur critique à éviter

Ne jamais calculer μ et σ sur l'ensemble complet (train + test) avant de scaler. Les statistiques du test contamineraient l'entraînement, ce qui fausse l'évaluation des performances réelles. On appelle ça une fuite de données.

Classification

Section 10

Introduction à la classification

En classification, la variable cible y est une catégorie discrète. L'objectif est d'apprendre une frontière qui sépare les classes dans l'espace des variables.

Binaire — y ∈ {0, 1}
Deux classes uniquement. Spam/légitime · Fraude/normal · Malade/sain.
Multi-classes — y ∈ {c₁, c₂, …, cₖ}
k classes. Chiffres 0–9 · Type de tumeur · Sentiment pos/neu/neg.

Pourquoi pas la régression linéaire pour classifier ?

Trois problèmes fondamentaux1. Sortie non bornée : ŷ peut valoir −0.3 ou 1.8 → pas interprétable comme probabilité 2. Sensibilité aux extrêmes : un point aberrant tire toute la droite 3. Mauvaise pénalisation : traite mal les cas clairement positifs ou négatifs → Solution : modèle dont la sortie est bornée dans (0, 1) → Régression Logistique
Section 11

Régression logistique

Malgré son nom, la régression logistique est un modèle de classification. Elle prédit la probabilité qu'un exemple appartienne à la classe 1, puis décide selon un seuil.

Modèle complet — deux étapesÉtape 1 : combinaison linéaire (comme la régression) z = θ₀ + θ₁·x₁ + θ₂·x₂ + … = θᵀx Étape 2 : sigmoïde → probabilité bornée dans (0, 1) hθ(x) = σ(z) = 1 / (1 + e⁻ᶻ) Étape 3 : décision (seuil par défaut = 0.5) ŷ = 1 si hθ(x) ≥ 0.5 | ŷ = 0 si hθ(x) < 0.5

Exemple numérique complet — diagnostic diabète

θ₀ = −8, θ₁ = 4 (glycémie g/L), θ₂ = 0.2 (IMC)Patient A — glycémie = 1.2 g/L, IMC = 24 z = −8 + 4×1.2 + 0.2×24 = −8 + 4.8 + 4.8 = +1.6 hθ(x) = 1/(1+e⁻¹·⁶) = 0.832 → ŷ = 1 (diabétique, 83 % de confiance) Patient B — glycémie = 0.8 g/L, IMC = 20 z = −8 + 4×0.8 + 0.2×20 = −0.8 hθ(x) = 1/(1+e⁰·⁸) = 0.310 → ŷ = 0 (non diabétique)
Interprétation des coefficients θ

Un coefficient positif (θ₁ = 4) signifie que quand cette variable augmente, la probabilité d'être en classe 1 augmente. Un coefficient négatif signifie l'inverse. Un coefficient proche de 0 signifie que la variable a peu d'influence.

Section 12

La fonction sigmoïde

La sigmoïde est le cœur de la régression logistique. Elle transforme n'importe quel réel en un nombre strictement entre 0 et 1, interprétable comme une probabilité.

Définition et propriétés clésσ(z) = 1 / (1 + e⁻ᶻ) z → +∞ : e⁻ᶻ → 0 → σ(z) → 1 z = 0 : e⁰ = 1 → σ(0) = 0.5 ← point d'inflexion z → −∞ : e⁻ᶻ → ∞ → σ(z) → 0 σ'(z) = σ(z)·(1 − σ(z)) ← dérivée exprimée via σ elle-même

Section 13

Frontière de décision

La frontière de décision sépare les exemples classés 1 de ceux classés 0. Elle correspond exactement à l'endroit où le modèle hésite : hθ(x) = 0.5, soit z = 0.

Equation de la frontière (en 2D : une droite)hθ(x) = 0.5 ⟺ σ(z) = 0.5 ⟺ z = 0 ⟺ θ₀ + θ₁·x₁ + θ₂·x₂ = 0 → En 2D (2 variables) : droite | En 3D : plan | En nD : hyperplan D'un côté : z > 0 → σ > 0.5 → classe 1 De l'autre : z < 0 → σ < 0.5 → classe 0

Section 14

Fonction de coût — Log Loss

On ne peut pas utiliser la MSE avec la sigmoïde car la fonction résultante n'est plus convexe. On utilise l'entropie croisée binaire (log loss), qui est convexe et pénalise fortement les erreurs confiantes.

Log Loss — Binary Cross-EntropyJ(θ) = −(1/m) · Σᵢ [ y⁽ⁱ⁾ · log(hθ(x⁽ⁱ⁾)) + (1−y⁽ⁱ⁾) · log(1−hθ(x⁽ⁱ⁾)) ] Quand y = 1 : coût actif = −log(hθ) → punit si hθ est proche de 0 Quand y = 0 : coût actif = −log(1−hθ) → punit si hθ est proche de 1
Cas y = 1 (positif attendu)
hθ=0.95 → −log(0.95) = 0.051 ✓ faible hθ=0.50 → −log(0.50) = 0.693 ⚠ hθ=0.05 → −log(0.05) = 2.996 ✗ fort
Cas y = 0 (négatif attendu)
hθ=0.05 → −log(0.95) = 0.051 ✓ faible hθ=0.50 → −log(0.50) = 0.693 ⚠ hθ=0.95 → −log(0.05) = 2.996 ✗ fort
Propriété clé — convexité

La log loss est convexe avec la sigmoïde → un seul minimum global → la descente de gradient converge toujours. Le gradient a la même forme qu'en régression : ∂J/∂θⱼ = (1/m)·Σᵢ(hθ(x⁽ⁱ⁾)−y⁽ⁱ⁾)·xⱼ⁽ⁱ⁾.

Gradient de la log loss (même forme que pour MSE)∂J/∂θⱼ = (1/m) · Σᵢ ( hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · xⱼ⁽ⁱ⁾ Mise à jour : θⱼ ← θⱼ − α · ∂J/∂θⱼ (simultanément pour tous j)

Section 16

Classification multi-classes

Pour C > 2 classes, deux stratégies principales :

One-vs-All (OvA)
Entraîner C classifieurs binaires. Chacun prédit "classe k vs tout le reste". On choisit la classe avec la probabilité maximale.
Simple · Rapide · C modèles à entraîner
Softmax (extension de σ)
P(y=k|x) = e^(θₖᵀx) / Σⱼ e^(θⱼᵀx)
C probabilités qui somment à 1 · Recommandé pour réseaux de neurones
Exemple Softmax — email en 3 classes (Spam / Promo / Légitime)θ₀ᵀx=2.1 → e²·¹=8.17 | θ₁ᵀx=0.5 → e⁰·⁵=1.65 | θ₂ᵀx=−0.3 → e⁻⁰·³=0.74 Somme = 10.56 P(Spam) = 8.17/10.56 = 0.774 (77.4 %) P(Promo) = 1.65/10.56 = 0.156 (15.6 %) P(Légit.) = 0.74/10.56 = 0.070 (7.0 %) → Classe prédite : Spam
Section 17

Arbres de décision — CART

Les arbres de décision apprennent une suite de règles hiérarchiques. À chaque nœud, on choisit la variable et le seuil qui séparent le mieux les classes selon l'impureté de Gini.

Indice de Gini — mesure d'impureté d'un nœud tGini(t) = 1 − Σₖ pₖ² pₖ = proportion d'exemples de classe k dans le nœud Gini = 0 → nœud pur (une seule classe) Gini = (C−1)/C → maximum (classes équiréparties) On choisit la coupure (variable xⱼ, seuil tⱼ) qui minimise : Gini_split = (nL/n)·Gini(tL) + (nR/n)·Gini(tR)

Visualisation — arbre sur données diabète

Overfitting des arbres profonds

Un arbre sans contrainte peut créer une règle pour chaque exemple : 100 % d'accuracy sur train, très mauvaise généralisation sur test. Solution : limiter la profondeur (max_depth) ou utiliser des méthodes d'ensemble.

Section 18

Méthodes d'ensemble

Combiner plusieurs modèles imparfaits produit un modèle global plus robuste. C'est le principe fondamental des méthodes d'ensemble.

Bagging — Random Forest

Construction parallèle d'arbres indépendants. Chaque arbre est entraîné sur un sous-échantillon bootstrap + sous-ensemble aléatoire de variables.

ŷ = mode(h₁(x), h₂(x), …, hT(x)) ← vote majoritaire
But : réduire la variance · Robuste au bruit
Boosting — Gradient Boosting

Construction séquentielle : chaque arbre corrige les erreurs du précédent en s'entraînant sur les résidus.

fm(x) = fm−1(x) + η·hm(x) ← η = learning rate
But : réduire le biais · XGBoost, LightGBM
CaractéristiqueRandom Forest (Bagging)Gradient Boosting

ImplémentationsRandomForest (sklearn)XGBoost · LightGBM · CatBoost
