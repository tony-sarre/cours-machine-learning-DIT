Section 01

Concepts fondamentaux

Le machine learning est une branche de l'intelligence artificielle permettant à une machine d'apprendre à partir de données, sans être explicitement programmée pour chaque tâche.

Définition formelle (Tom Mitchell, 1998)

Définition formelle On dit qu'un programme informatique apprend à partir d'une expérience E concernant une tâche T et une mesure de performance P, si ses performances sur T, mesurées par P, s'améliorent avec l'expérience E.

Les trois types d'apprentissage

Supervisé
( X , y )
Données étiquetées. La machine apprend à partir de paires entrée/sortie connues.
Non supervisé
( X )
Pas de labels. La machine découvre des structures cachées dans les données.
Par renforcement
r ( s, a )
Apprentissage par récompense. L'agent apprend en interagissant avec un environnement.

Exemple : jeu de dames (Arthur Samuel, 1959)

Application du cadre T–E–P Tâche T = jouer au jeu de dames Expérience E = le programme joue des milliers de parties contre lui-même Performance P = probabilité de gagner la prochaine partie Si P augmente avec E → le programme a appris

Apprentissage supervisé — deux familles

Régression

La sortie y est une valeur numérique continue.
Exemples : prix d'une maison, température, poids.

ŷ ∈ ℝ → une valeur réelle quelconque
Classification

La sortie y est une classe discrète.
Exemples : spam/non-spam, chat/chien, diagnostic.

ŷ ∈ {0, 1, 2, ...} → une catégorie
Section 02

Le modèle linéaire

La régression linéaire simple modélise la relation entre une variable d'entrée x et une variable de sortie y par une droite.

Équation du modèle

Hypothèse — régression linéaire simple ŷ = w · x + b où : ŷ = prédiction du modèle (prix estimé, en k€) x = variable d'entrée (surface, en m²) w = coefficient directeur (pente) — influence de x sur ŷ b = biais / ordonnée à l'origine — valeur de ŷ quand x = 0
Interprétation de w

Si w = 2.5, cela signifie que chaque m² supplémentaire prédit une hausse de 2.5 k€ du prix. C'est la "sensibilité" du prix à la surface.

Section 03

La fonction de coût J(w, b)

Pour mesurer la qualité d'un modèle, on a besoin d'une fonction de coût J qui quantifie l'écart total entre les prédictions ŷ et les valeurs réelles y. L'objectif est de trouver w et b qui minimisent J.

Pourquoi l'erreur au carré ?

Comparaison des critères d'erreur Option 1 — erreur absolue : Σ|ŷ⁽ⁱ⁾ − y⁽ⁱ⁾| Problème : non dérivable en 0 → impossible d'utiliser le gradient Option 2 — erreur au carré : Σ(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)² Avantages : différentiable partout, pénalise davantage les grandes erreurs, donne une surface convexe avec un minimum global unique

Définition formelle de J

MSE — Mean Squared Error (Erreur Quadratique Moyenne) J(w, b) = 1/(2m) · Σᵢ₌₁ᵐ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ )² En substituant ŷ⁽ⁱ⁾ = wx⁽ⁱ⁾ + b : J(w, b) = 1/(2m) · Σᵢ₌₁ᵐ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )² où m = nombre d'exemples d'entraînement ŷ⁽ⁱ⁾ = wx⁽ⁱ⁾ + b est la prédiction pour l'exemple i y⁽ⁱ⁾ est la vraie valeur pour l'exemple i
Pourquoi 1/(2m) et non 1/m ?

Le facteur 2 au dénominateur est une convention de commodité : lors du calcul des dérivées, la règle de dérivation du carré fait apparaître un facteur 2 au numérateur. Ce 2 se simplifie avec le 2 du dénominateur, rendant les formules plus propres. La valeur minimale de J change, mais le point où ce minimum est atteint (les valeurs optimales de w et b) reste identique.

Propriété fondamentale : convexité de J

Preuve de la convexité J(w,b) = (1/2m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )² Chaque terme fᵢ(w,b) = ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )² est convexe car c'est le carré d'une fonction affine de (w,b). La somme de fonctions convexes est convexe → J est convexe. La matrice Hessienne de J est semi-définie positive (H ≽ 0) → J a exactement un seul minimum global, aucun minimum local. → La descente de gradient converge toujours vers ce minimum.
Conséquence importante

Parce que J est convexe, quelle que soit l'initialisation de w et b, la descente de gradient atteindra le même minimum global. Cette propriété disparaît pour les réseaux de neurones profonds, où J n'est plus convexe.

Section 04

Calcul des dérivées partielles

Pour minimiser J(w,b), on a besoin de savoir dans quelle direction se déplacer. Le gradient de J nous donne cette information : c'est le vecteur des dérivées partielles ∂J/∂w et ∂J/∂b.

Outil mathématique : règle de dérivation composée (chain rule)

Rappel — règle des fonctions composées Si f(u) = u² et u = g(w) alors : d/dw [ f(g(w)) ] = f'(g(w)) · g'(w) = 2·g(w) · g'(w) Appliqué ici : f(u) = u², u = uᵢ = wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ d/dw [ uᵢ² ] = 2·uᵢ · (∂uᵢ/∂w)

Dérivée partielle par rapport à w — démonstration complète

1
Point de départ :
J(w,b) = (1/2m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )²
2
On pose uᵢ = wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ (l'erreur du modèle sur l'exemple i) :
J = (1/2m) · Σᵢ uᵢ²
3
La dérivée d'une somme = somme des dérivées :
∂J/∂w = (1/2m) · Σᵢ ∂/∂w [uᵢ²]
4
Appliquer la rule de dérivation du carré (chain rule) :
∂/∂w [uᵢ²] = 2·uᵢ · ∂uᵢ/∂w
5
Calculer ∂uᵢ/∂w (b et y⁽ⁱ⁾ sont constants par rapport à w) :
uᵢ = w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾ → ∂uᵢ/∂w = x⁽ⁱ⁾
6
Substituer et simplifier (le 2 se compense avec le 2 du dénominateur) :
∂J/∂w = (1/2m) · Σᵢ 2·uᵢ·x⁽ⁱ⁾ = (1/m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ ) · x⁽ⁱ⁾

Résultat final :   ∂J/∂w = (1/m) · Σᵢ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ ) · x⁽ⁱ⁾

Dérivée partielle par rapport à b — démonstration complète

1
Même point de départ, même développement jusqu'à :
∂J/∂b = (1/2m) · Σᵢ 2·uᵢ · ∂uᵢ/∂b
2
Calculer ∂uᵢ/∂b (wx⁽ⁱ⁾ et y⁽ⁱ⁾ sont constants par rapport à b) :
uᵢ = wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ → ∂uᵢ/∂b = 1
3
Substituer et simplifier :
∂J/∂b = (1/2m) · Σᵢ 2·uᵢ · 1 = (1/m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )

Résultat final :   ∂J/∂b = (1/m) · Σᵢ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ )

Interprétation géométrique du signe du gradient

Que nous dit le signe de ∂J/∂w ? ∂J/∂w > 0 → J croît quand w augmente → il faut diminuer w ∂J/∂w < 0 → J décroît quand w augmente → il faut augmenter w ∂J/∂w = 0 → on est au minimum par rapport à w → convergé ✓ Même raisonnement symétrique pour ∂J/∂b.
Section 05

Algorithme de descente de gradient

La descente de gradient est la méthode qui permet de trouver w et b de façon itérative, en se déplaçant toujours dans la direction qui fait descendre J le plus vite.

Analogie intuitive

Imaginez-vous dans le brouillard sur une montagne. Vous voulez atteindre la vallée (le minimum de J). Vous ne voyez pas loin, mais vous sentez la pente sous vos pieds. Vous n'avez qu'à toujours faire un pas dans la direction la plus raide vers le bas. En répétant cela assez de fois, vous atteignez la vallée. C'est exactement ça, la descente de gradient.

Règle de mise à jour — forme complète

Mise à jour SIMULTANÉE à chaque itération t w_new = w − α · ∂J/∂w b_new = b − α · ∂J/∂b
w ← w_new (mise à jour après avoir calculé les deux gradients) b ← b_new En développant les gradients (calculés en Section 04) : w ← w − α · (1/m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ ) · x⁽ⁱ⁾ b ← b − α · (1/m) · Σᵢ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )
Attention — la simultanéité est obligatoire

On calcule les deux gradients avec les anciennes valeurs de w et b, puis on met à jour les deux ensemble. Si on mettait à jour w d'abord et utilisait le nouveau w pour calculer le gradient de b, on minimiserait une fonction différente de J — l'algorithme serait incorrect.

Le taux d'apprentissage α — rôle et choix

Impact de α sur la convergence α trop grand → le pas dépasse le minimum → divergence (J augmente) α trop petit → convergence très lente (des milliers d'itérations) α optimal → J décroît régulièrement, convergence en ~100–1000 itérations Valeurs typiques à tester : 0.001, 0.003, 0.01, 0.03, 0.1 (progression ×3)

Critère d'arrêt

Deux conditions équivalentes de convergence Condition 1 — sur le coût : | J⁽ᵗ⁾ − J⁽ᵗ⁻¹⁾ | < ε avec ε ≈ 10⁻⁵ Condition 2 — sur le gradient : ||∇J|| = √( (∂J/∂w)² + (∂J/∂b)² ) → 0 La convexité de J garantit que ces conditions sont atteintes.

Preuve de convergence (esquisse)

Théorème de convergence pour fonctions convexes Lipschitz-continues J est convexe et ∇J est L-Lipschitz continue. Pour α < 1/L, on peut montrer que : J(w_{t+1}, b_{t+1}) ≤ J(w_t, b_t) − (α/2) · ||∇J(w_t, b_t)||² → J décroît strictement à chaque itération tant que ||∇J|| ≠ 0 → J est minorée par 0 → la suite des J_t converge → (w_t, b_t) converge vers le minimiseur global (w*, b*) Honnêteté importante : cette garantie suppose la convexité de J. Pour les réseaux de neurones (non convexes), on converge vers un minimum local, non nécessairement global.

Section 06

Régression linéaire multiple

En régression simple, une seule variable x explique y. En régression multiple, plusieurs variables x₁, x₂, …, xₙ expliquent y ensemble. On suit exactement le même raisonnement — modèle, coût, gradients, mise à jour — en généralisant chaque étape.

Ce qui change et ce qui reste identique

Ce qui change : il y a maintenant n+1 paramètres à apprendre au lieu de 2. Ce qui reste identique : la fonction de coût J, la forme des gradients, et la règle de mise à jour. L'algorithme est le même.

Étape 2 — Le modèle avec 2 variables

Avec une seule variable, le modèle était une droite : ŷ = wx + b. Avec deux variables, le modèle est un plan :

Modèle à 2 variables explicatives ŷ = θ₀ + θ₁·x₁ + θ₂·x₂ où : θ₀ = biais (constante) — remplace b de la régression simple θ₁ = coefficient de x₁ (surface) — remplace w θ₂ = coefficient de x₂ (chambres) Il y a maintenant 3 paramètres à apprendre : θ₀, θ₁, θ₂
Lien avec la régression simple

La régression simple est un cas particulier où n = 1 : on avait θ₁ = w et θ₀ = b. La régression multiple avec n = 2 ajoute simplement θ₂·x₂. La logique est identique.

Étape 3 — La fonction de coût J(θ₀, θ₁, θ₂)

La fonction de coût a exactement la même forme qu'en régression simple. Seul le calcul de ŷ⁽ⁱ⁾ change : il utilise maintenant les deux variables.

Fonction de coût — régression multiple à 2 variables J(θ₀, θ₁, θ₂) = 1/(2m) · Σᵢ₌₁ᵐ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ )² avec ŷ⁽ⁱ⁾ = θ₀ + θ₁·x₁⁽ⁱ⁾ + θ₂·x₂⁽ⁱ⁾ C'est exactement la même formule qu'en régression simple. La différence est uniquement dans le calcul de ŷ⁽ⁱ⁾.

Étape 4 — Les trois dérivées partielles

On doit maintenant calculer trois gradients : un pour chaque paramètre θ₀, θ₁, θ₂. Le calcul est identique à celui de la régression simple — on applique la même chain rule.

Dérivée par rapport à θ₀ (le biais) ∂J/∂θ₀ = (1/m) · Σᵢ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ ) C'est exactement ∂J/∂b de la régression simple. Le biais θ₀ est multiplié par 1 dans le modèle → sa dérivée vaut 1.
Dérivée par rapport à θ₁ (coefficient de x₁ — surface) ∂J/∂θ₁ = (1/m) · Σᵢ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ ) · x₁⁽ⁱ⁾ C'est exactement ∂J/∂w de la régression simple, avec x₁ à la place de x. θ₁ est multiplié par x₁ dans le modèle → sa dérivée vaut x₁.
Dérivée par rapport à θ₂ (coefficient de x₂ — chambres) ∂J/∂θ₂ = (1/m) · Σᵢ ( ŷ⁽ⁱ⁾ − y⁽ⁱ⁾ ) · x₂⁽ⁱ⁾ Même structure que ∂J/∂θ₁, avec x₂ à la place de x₁. θ₂ est multiplié par x₂ dans le modèle → sa dérivée vaut x₂.
Règle générale à retenir

Pour tout paramètre θⱼ qui multiplie la variable xⱼ dans le modèle, le gradient est : ∂J/∂θⱼ = (1/m) · Σᵢ (erreur⁽ⁱ⁾) · xⱼ⁽ⁱ⁾. Cette structure est universelle — elle s'applique quel que soit n.

Étape 6 — Mise à jour des trois paramètres

On applique la règle de descente de gradient pour chacun des trois paramètres, simultanément, avec α = 0.0001.

Pourquoi α = 0.0001 et non 0.0032 ?

Les variables x₁ (surface, de 50 à 130) ont des valeurs bien plus grandes que x (surface seule, même ordre). Le gradient ∂J/∂θ₁ est lui aussi beaucoup plus grand (−22900 vs −235). Avec α = 0.0032, le pas serait gigantesque et le modèle divergerait. C'est pourquoi le feature scaling (section 07) est indispensable en régression multiple.

Itération 1 — mise à jour simultanée, α = 0.0001 θ₀_new = 0 − 0.0001 × (−235.00) = 0.02350 θ₁_new = 0 − 0.0001 × (−22900.00) = 2.29000 θ₂_new = 0 − 0.0001 × (−636.67) = 0.06367 Vérification : ŷ⁽¹⁾ après mise à jour : ŷ⁽¹⁾ = 0.0235 + 2.29×50 + 0.0637×1 = 0.0235 + 114.5 + 0.0637 = 114.59 k€ y⁽¹⁾ = 155 k€ → erreur résiduelle = −40.41 k€ (contre −155 k€ avant) J a bien diminué après une seule itération.

Étape 7 — L'algorithme complet

On répète les étapes 4, 5 et 6 jusqu'à convergence. À chaque itération, on recalcule les ŷ⁽ⁱ⁾ avec les paramètres courants, on calcule les trois gradients, puis on met à jour simultanément θ₀, θ₁ et θ₂.

Algorithme complet — régression multiple à n variables Initialiser : θ₀ = 0, θ₁ = 0, θ₂ = 0, …, θₙ = 0 Répéter jusqu'à convergence : 1. Calculer toutes les prédictions : ŷ⁽ⁱ⁾ = θ₀ + θ₁·x₁⁽ⁱ⁾ + θ₂·x₂⁽ⁱ⁾ + … + θₙ·xₙ⁽ⁱ⁾ pour i = 1 … m 2. Calculer J : J = (1/2m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)² 3. Calculer les n+1 gradients simultanément : ∂J/∂θⱼ = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · xⱼ⁽ⁱ⁾ pour j = 0 … n (avec x₀⁽ⁱ⁾ = 1 pour tous les i) 4. Mettre à jour simultanément tous les θⱼ : θⱼ ← θⱼ − α · ∂J/∂θⱼ pour j = 0 … n Arrêter quand |J⁽ᵗ⁾ − J⁽ᵗ⁻¹⁾| < ε

Étape 8 — Résultat après convergence et prédiction

Après convergence, on obtient les valeurs optimales de θ₀, θ₁ et θ₂. On peut alors faire des prédictions sur de nouvelles maisons.

Valeurs convergées sur notre jeu de données (calculées analytiquement) θ₀ ≈ 40.0 (base) θ₁ ≈ 1.85 k€ par m² supplémentaire θ₂ ≈ 10.0 k€ par chambre supplémentaire Modèle final : ŷ = 40.0 + 1.85·x₁ + 10.0·x₂
Interprétation des coefficients

θ₁ = 1.85 signifie : toutes choses égales par ailleurs (même nombre de chambres), chaque m² supplémentaire ajoute 1.85 k€. θ₂ = 10.0 signifie : à surface égale, chaque chambre supplémentaire ajoute 10 k€. Cette interprétation "toutes choses égales par ailleurs" est la force de la régression multiple par rapport à des comparaisons brutes.

Étape 9 — Généralisation à n variables quelconques

Tout ce qui précède s'applique sans modification pour n = 3, 4, 100, 1000 variables. La seule différence est le nombre de paramètres θ et de gradients à calculer.

Section 07

Feature Scaling — mise à l'échelle

Quand les variables ont des ordres de grandeur très différents (ex : surface en m² entre 40 et 150, vs ancienneté entre 0 et 50), la descente de gradient converge lentement et de façon irrégulière.

Pourquoi le scaling est nécessaire

Problème sans scaling — courbes de niveau elliptiques Si x₁ ∈ [10 000 ; 100 000] et x₂ ∈ [1 ; 10] θ₁ doit être très petit (ex : 0.001) pour que θ₁·x₁ reste raisonnable θ₂ peut être grand (ex : 10) → Les courbes de niveau de J forment une ellipse très allongée → La descente de gradient oscille et converge lentement → Avec scaling : les courbes deviennent quasi-circulaires → La descente converge en ligne droite, beaucoup plus vite

Normalisation min-max

Min-max scaling — ramène toutes les valeurs entre 0 et 1 x' = ( x − min(x) ) / ( max(x) − min(x) ) Résultat : x' ∈ [0, 1] pour tous les exemples Avantage : préserve la forme de la distribution Inconvénient : sensible aux valeurs aberrantes (outliers) Exemple : surface ∈ [40, 130] x' = (x − 40) / (130 − 40) = (x − 40) / 90 → 40m² → 0.0 → 85m² → 0.5 → 130m² → 1.0

Standardisation (z-score)

Standardisation — centre réduit (moyenne 0, écart-type 1) x' = ( x − μ ) / σ où μ = moyenne de x sur le dataset d'entraînement σ = écart-type de x sur le dataset d'entraînement Résultat : μ' = 0, σ' = 1 pour chaque feature standardisée Avantage : robuste aux outliers, efficace si la distribution est normale Règle critique : calculer μ et σ uniquement sur le training set, puis appliquer ces mêmes μ et σ au validation et test set.
Erreur fréquente à éviter

Ne jamais calculer μ et σ sur l'ensemble complet (training + test) avant de scaler. Cela constitue une fuite de données (data leakage) : les statistiques du test contaminent l'entraînement, ce qui fausse l'évaluation des performances réelles.

Section 08

Métriques d'évaluation

Une fois le modèle entraîné, on mesure sa qualité avec des métriques standardisées. Ces métriques sont calculées sur des données de test jamais vues pendant l'entraînement.

MSE — Mean Squared Error

Erreur quadratique moyenne MSE = (1/n) · Σᵢ ( yᵢ − ŷᵢ )² Propriétés : → Toujours ≥ 0 → MSE = 0 ↔ prédictions parfaites → Pénalise fortement les grandes erreurs (carré) → Unité : (unité de y)² → difficile à interpréter directement

RMSE — Root Mean Squared Error

Racine de la MSE — dans la même unité que y RMSE = √MSE = √[ (1/n) · Σᵢ ( yᵢ − ŷᵢ )² ] Avantage : même unité que y → interprétable directement Si RMSE = 12 k€ → en moyenne, nos prédictions s'écartent de ±12 k€ du prix réel

R² — Coefficient de détermination

Proportion de variance expliquée par le modèle R² = 1 − [ Σᵢ(yᵢ − ŷᵢ)² ] / [ Σᵢ(yᵢ − ȳ)² ] = 1 − SS_res / SS_tot où SS_res = Σ(yᵢ − ŷᵢ)² (variance résiduelle — erreurs du modèle) SS_tot = Σ(yᵢ − ȳ)² (variance totale — de la variable cible) Interprétation : R² = 1.0 → prédictions parfaites (0% de variance inexpliquée) R² = 0.0 → le modèle ne fait pas mieux que prédire ȳ constamment R² = 0.85 → le modèle explique 85% de la variance de y R² < 0 → le modèle est pire que prédire la moyenne (underfitting sévère)
