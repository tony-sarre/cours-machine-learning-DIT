Chapitre Premier

Fondements du Machine Learning

Section 01

Concepts fondamentaux

Le machine learning est une branche de l'intelligence artificielle qui permet à une machine d'apprendre à partir de données sans être explicitement programmée pour chaque tâche. Au lieu de coder des règles à la main, on laisse la machine les inférer à partir d'exemples.

Définition formelle - Tom Mitchell (1998)

Définition officielleOn dit qu'un programme informatique apprend à partir d'une expérience E concernant une tâche T et une mesure de performance P, si ses performances sur T, mesurées par P, s'améliorent avec l'expérience E.
T - Tâche
Ce que le système doit accomplir : classer, prédire, jouer, filtrer...
E - Expérience
Les données sur lesquelles le système s'entraîne. Sans données, pas d'apprentissage.
P - Performance
Mesure objective. Doit être calculée sur de nouvelles données jamais vues.

Les trois types d'apprentissage

Supervisé - (X, y)
ŷ = f(x)
Données étiquetées. On apprend à prédire y à partir de x.

Exemples : prix, spam, diagnostic.
Non supervisé - (X)
clusters(X)
Pas de labels. La machine découvre des structures cachées.

Exemples : segmentation, compression.
Par renforcement - r(s,a)
max r
Apprentissage par récompense. L'agent interagit avec son environnement.

Exemples : AlphaGo, robots.

Supervisé - deux familles de problèmes

Régression

La sortie y est une valeur numérique continue.

ŷ ∈ ℝ → ex : 234.5 k€, 37.2°C
Classification

La sortie y est une catégorie discrète.

ŷ ∈ {0, 1, ...} → ex : spam, chat/chien

Régression Linéaire

Section 02

Le modèle linéaire ŷ = wx + b

La régression linéaire simple modélise la relation entre une variable d'entrée x et une variable de sortie y par une droite. C'est le modèle supervisé le plus fondamental.

Hypothèse - régression linéaire simpleŷ = w · x + b ŷ = prédiction du modèle (≠ y, la vraie valeur) x = variable d'entrée (ex : surface en m²) w = pente - variation de ŷ par unité de x b = biais - valeur de ŷ quand x = 0
Interprétation concrète

Si w = 2.5 et b = 40, pour une maison de 80 m² : ŷ = 2.5 × 80 + 40 = 240 k€. Chaque m² supplémentaire ajoute 2.5 k€ - c'est w, la "sensibilité" du prix à la surface.

Données d'exemple - 10 maisons

Section 03

La fonction de coût J(w, b)

Pour mesurer la qualité d'un modèle, on définit une fonction de coût J qui quantifie l'écart entre les prédictions ŷ et les valeurs réelles y. L'objectif est de trouver w et b qui minimisent J.

MSE - Mean Squared Error (avec convention 1/2m)J(w, b) = 1/(2m) · Σᵢ₌₁ᵐ ( wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ )² m = nombre d'exemples · le ½ simplifie les calculs de dérivées Convexité : J est une parabole → un seul minimum global → gradient converge toujours
Pourquoi l'erreur au carré, pas l'erreur absolue ?

L'erreur absolue |ŷ−y| n'est pas dérivable en 0, ce qui rend le gradient inutilisable. L'erreur au carré est dérivable partout, pénalise davantage les grandes erreurs, et produit une surface convexe avec un unique minimum global garanti.

Parabole J(w) - convexité visuelle

Section 04

Calcul des dérivées partielles

Pour descendre vers le minimum de J, il faut savoir dans quelle direction se déplacer. Le gradient - vecteur des dérivées partielles - donne cette information.

Démonstration de ∂J/∂w

1
Départ : J(w,b) = (1/2m) · Σᵢ (wx⁽ⁱ⁾ + b − y⁽ⁱ⁾)²
2
Poser uᵢ = wx⁽ⁱ⁾ + b − y⁽ⁱ⁾ : J = (1/2m) · Σᵢ uᵢ²
3
Chain rule : ∂(uᵢ²)/∂w = 2uᵢ · ∂uᵢ/∂w ; or uᵢ = w·xᵢ + b − yᵢ → ∂uᵢ/∂w = xᵢ
4
Simplifier (le 2 se compense) : ∂J/∂w = (1/m) · Σᵢ (wx⁽ⁱ⁾ + b − y⁽ⁱ⁾) · x⁽ⁱ⁾

Résultats :
∂J/∂w = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · x⁽ⁱ⁾
∂J/∂b = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)

Calcul numérique - itération 0

Calcul numérique - w=0, b=0
Interprétation du signe du gradient∂J/∂w > 0 → J croît quand w augmente → il faut diminuer w ∂J/∂w < 0 → J décroît quand w augmente → il faut augmenter w ∂J/∂w = 0 → minimum atteint pour w → convergé ✓
Section 05

Algorithme de descente de gradient

La descente de gradient trouve w et b de façon itérative, en se déplaçant à chaque étape dans la direction qui fait baisser J le plus vite.

Analogie - descendre dans le brouillard

Imaginez-vous sur une colline dans le brouillard, cherchant la vallée. Vous ne voyez pas loin, mais vous sentez la pente sous vos pieds. Vous faites un petit pas dans la direction la plus raide vers le bas, et vous recommencez. En répétant cela, vous atteignez la vallée. C'est la descente de gradient.

Mise à jour SIMULTANÉE à chaque itérationw_new = w − α · ∂J/∂w = w − α · (1/m) · Σᵢ(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)·x⁽ⁱ⁾ b_new = b − α · ∂J/∂b = b − α · (1/m) · Σᵢ(ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) w ← w_new ; b ← b_new (après avoir calculé les deux)
La simultanéité est obligatoire

On calcule les deux gradients avec les anciennes valeurs de w et b, puis on met à jour les deux ensemble. Mettre à jour w en premier et l'utiliser pour calculer le gradient de b produirait un algorithme incorrect - on minimiserait une autre fonction que J.

Impact de α - taux d'apprentissageα trop grand → le pas dépasse le minimum → J diverge α trop petit → convergence très lente (milliers d'itérations) α optimal → J décroît régulièrement et se stabilise Valeurs typiques à tester : 0.001 → 0.003 → 0.01 → 0.03 → 0.1 (×3 à chaque fois)

Section 06

Régression linéaire multiple

En pratique, plusieurs variables expliquent y ensemble. La régression multiple généralise le modèle à n variables d'entrée. La logique mathématique est exactement la même.

Modèle généralisé à n variablesŷ = θ₀ + θ₁·x₁ + θ₂·x₂ + … + θₙ·xₙ = θᵀx θ₀ = biais · θ₁…θₙ = poids · Total : n+1 paramètres Gradients : ∂J/∂θⱼ = (1/m) · Σᵢ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾) · xⱼ⁽ⁱ⁾ (j = 0…n, avec x₀ = 1)
Règle universelle

Pour tout paramètre θⱼ : ∂J/∂θⱼ = (1/m) · Σᵢ(erreur)·xⱼ. Cette structure est identique quel que soit n. Comprendre la régression simple suffit pour généraliser à n dimensions.

Section 07

Feature Scaling

Quand les variables ont des ordres de grandeur très différents, la descente de gradient converge lentement et de façon irrégulière. Le scaling est un prétraitement indispensable.

Normalisation min-max
x' = (x − min(x)) / (max(x) − min(x))
Résultat : x' ∈ [0, 1]
Sensible aux valeurs aberrantes
Standardisation (z-score)
x' = (x − μ) / σ
Résultat : moyenne=0, σ=1
Robuste aux outliers
μ et σ calculés sur train uniquement
Data leakage - erreur critique à éviter

Ne jamais calculer μ et σ sur l'ensemble complet (train + test) avant de scaler. Les statistiques du test contamineraient l'entraînement, ce qui fausse l'évaluation des performances réelles. On appelle ça une fuite de données.

Classification

Section 10

Introduction à la classification

En classification, la variable cible y est une catégorie discrète. L'objectif est d'apprendre une frontière qui sépare les classes dans l'espace des variables.

Binaire - y ∈ {0, 1}
Deux classes uniquement. Spam/légitime · Fraude/normal · Malade/sain.
Multi-classes - y ∈ {c₁, c₂, …, cₖ}
k classes. Chiffres 0–9 · Type de tumeur · Sentiment pos/neu/neg.

Pourquoi pas la régression linéaire pour classifier ?

Trois problèmes fondamentaux1. Sortie non bornée : ŷ peut valoir −0.3 ou 1.8 → pas interprétable comme probabilité 2. Sensibilité aux extrêmes : un point aberrant tire toute la droite 3. Mauvaise pénalisation : traite mal les cas clairement positifs ou négatifs → Solution : modèle dont la sortie est bornée dans (0, 1) → Régression Logistique
Section 11

Régression logistique

Malgré son nom, la régression logistique est un modèle de classification. Elle prédit la probabilité qu'un exemple appartienne à la classe 1, puis décide selon un seuil.

Modèle complet - deux étapesÉtape 1 : combinaison linéaire (comme la régression) z = θ₀ + θ₁·x₁ + θ₂·x₂ + … = θᵀx Étape 2 : sigmoïde → probabilité bornée dans (0, 1) hθ(x) = σ(z) = 1 / (1 + e⁻ᶻ) Étape 3 : décision (seuil par défaut = 0.5) ŷ = 1 si hθ(x) ≥ 0.5 | ŷ = 0 si hθ(x) < 0.5

Exemple numérique complet - diagnostic diabète

θ₀ = −8, θ₁ = 4 (glycémie g/L), θ₂ = 0.2 (IMC)Patient A - glycémie = 1.2 g/L, IMC = 24 z = −8 + 4×1.2 + 0.2×24 = −8 + 4.8 + 4.8 = +1.6 hθ(x) = 1/(1+e⁻¹·⁶) = 0.832 → ŷ = 1 (diabétique, 83 % de confiance) Patient B - glycémie = 0.8 g/L, IMC = 20 z = −8 + 4×0.8 + 0.2×20 = −0.8 hθ(x) = 1/(1+e⁰·⁸) = 0.310 → ŷ = 0 (non diabétique)
Interprétation des coefficients θ

Un coefficient positif (θ₁ = 4) signifie que quand cette variable augmente, la probabilité d'être en classe 1 augmente. Un coefficient négatif signifie l'inverse. Un coefficient proche de 0 signifie que la variable a peu d'influence.

Section 12

La fonction sigmoïde

La sigmoïde est le cœur de la régression logistique. Elle transforme n'importe quel réel en un nombre strictement entre 0 et 1, interprétable comme une probabilité.

Définition et propriétés clésσ(z) = 1 / (1 + e⁻ᶻ) z → +∞ : e⁻ᶻ → 0 → σ(z) → 1 z = 0 : e⁰ = 1 → σ(0) = 0.5 ← point d'inflexion z → −∞ : e⁻ᶻ → ∞ → σ(z) → 0 σ'(z) = σ(z)·(1 − σ(z)) ← dérivée exprimée via σ elle-même

Frontière de décision

La frontière de décision sépare les exemples classés 1 de ceux classés 0. Elle correspond exactement à l'endroit où le modèle hésite : hθ(x) = 0.5, soit z = 0.

Equation de la frontière (en 2D : une droite)hθ(x) = 0.5 ⟺ σ(z) = 0.5 ⟺ z = 0 ⟺ θ₀ + θ₁·x₁ + θ₂·x₂ = 0 → En 2D (2 variables) : droite | En 3D : plan | En nD : hyperplan D'un côté : z > 0 → σ > 0.5 → classe 1 De l'autre : z < 0 → σ < 0.5 → classe 0

Section 14

Fonction de coût - Log Loss

On ne peut pas utiliser la MSE avec la sigmoïde car la fonction résultante n'est plus convexe. On utilise l'entropie croisée binaire (log loss), qui est convexe et pénalise fortement les erreurs confiantes.

Log Loss - Binary Cross-EntropyJ(θ) = −(1/m) · Σᵢ [ y⁽ⁱ⁾ · log(hθ(x⁽ⁱ⁾)) + (1−y⁽ⁱ⁾) · log(1−hθ(x⁽ⁱ⁾)) ] Quand y = 1 : coût actif = −log(hθ) → punit si hθ est proche de 0 Quand y = 0 : coût actif = −log(1−hθ) → punit si hθ est proche de 1
Cas y = 1 (positif attendu)
hθ=0.95 → −log(0.95) = 0.051 ✓ faible hθ=0.50 → −log(0.50) = 0.693 ⚠ hθ=0.05 → −log(0.05) = 2.996 ✗ fort
Cas y = 0 (négatif attendu)
hθ=0.05 → −log(0.95) = 0.051 ✓ faible hθ=0.50 → −log(0.50) = 0.693 ⚠ hθ=0.95 → −log(0.05) = 2.996 ✗ fort
Propriété clé - convexité

La log loss est convexe avec la sigmoïde → un seul minimum global → la descente de gradient converge toujours. Le gradient a la même forme qu'en régression : ∂J/∂θⱼ = (1/m)·Σᵢ(hθ(x⁽ⁱ⁾)−y⁽ⁱ⁾)·xⱼ⁽ⁱ⁾.

Gradient de la log loss (même forme que pour MSE)∂J/∂θⱼ = (1/m) · Σᵢ ( hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · xⱼ⁽ⁱ⁾ Mise à jour : θⱼ ← θⱼ − α · ∂J/∂θⱼ (simultanément pour tous j)

Section 16

Classification multi-classes

Pour C > 2 classes, deux stratégies principales :

One-vs-All (OvA)
Entraîner C classifieurs binaires. Chacun prédit "classe k vs tout le reste". On choisit la classe avec la probabilité maximale.
Simple · Rapide · C modèles à entraîner
Softmax (extension de σ)
P(y=k|x) = e^(θₖᵀx) / Σⱼ e^(θⱼᵀx)
C probabilités qui somment à 1 · Recommandé pour réseaux de neurones
Exemple Softmax - email en 3 classes (Spam / Promo / Légitime)θ₀ᵀx=2.1 → e²·¹=8.17 | θ₁ᵀx=0.5 → e⁰·⁵=1.65 | θ₂ᵀx=−0.3 → e⁻⁰·³=0.74 Somme = 10.56 P(Spam) = 8.17/10.56 = 0.774 (77.4 %) P(Promo) = 1.65/10.56 = 0.156 (15.6 %) P(Légit.) = 0.74/10.56 = 0.070 (7.0 %) → Classe prédite : Spam
Section 17

Arbres de décision - CART

Les arbres de décision apprennent une suite de règles hiérarchiques. À chaque nœud, on choisit la variable et le seuil qui séparent le mieux les classes selon l'impureté de Gini.

Indice de Gini - mesure d'impureté d'un nœud tGini(t) = 1 − Σₖ pₖ² pₖ = proportion d'exemples de classe k dans le nœud Gini = 0 → nœud pur (une seule classe) Gini = (C−1)/C → maximum (classes équiréparties) On choisit la coupure (variable xⱼ, seuil tⱼ) qui minimise : Gini_split = (nL/n)·Gini(tL) + (nR/n)·Gini(tR)

Visualisation - arbre sur données diabète

Overfitting des arbres profonds

Un arbre sans contrainte peut créer une règle pour chaque exemple : 100 % d'accuracy sur train, très mauvaise généralisation sur test. Solution : limiter la profondeur (max_depth) ou utiliser des méthodes d'ensemble.

Section 18

Méthodes d'ensemble

Combiner plusieurs modèles imparfaits produit un modèle global plus robuste. C'est le principe fondamental des méthodes d'ensemble.

Bagging - Random Forest

Construction parallèle d'arbres indépendants. Chaque arbre est entraîné sur un sous-échantillon bootstrap + sous-ensemble aléatoire de variables.

ŷ = mode(h₁(x), h₂(x), …, hT(x)) ← vote majoritaire
But : réduire la variance · Robuste au bruit
Boosting - Gradient Boosting

Construction séquentielle : chaque arbre corrige les erreurs du précédent en s'entraînant sur les résidus.

fm(x) = fm−1(x) + η·hm(x) ← η = learning rate
But : réduire le biais · XGBoost, LightGBM
CaractéristiqueRandom Forest (Bagging)Gradient Boosting

ObjectifRéduire la varianceRéduire le biais
Sensibilité au bruitRobustePlus sensible

I Introduction

Principes de l'apprentissage non supervisé

Section 01

Apprentissage non supervisé

Dans l'apprentissage supervisé, chaque exemple (xi, yi) est étiqueté - on connaît la réponse attendue. Dans l'apprentissage non supervisé, on ne dispose que des données X, sans labels. La machine doit découvrir par elle-même la structure cachée dans ces données.

Supervisé - (X, y)
On connaît les réponses. On apprend une fonction f : X → y.

Ex : prédire si un email est spam (y = 0 ou 1).
Non supervisé - (X seulement)
Pas de labels. On cherche des patterns, des groupes, des structures.

Ex : regrouper des clients sans savoir à l'avance combien il y a de types.

Deux grandes familles de problèmes

Clustering (regroupement)

Trouver des groupes naturels dans les données. Les exemples d'un même groupe sont similaires entre eux et différents des autres groupes.

K-Means · CAH · GMM · DBSCAN
Réduction de dimensionnalité

Compresser les données en gardant l'essentiel. Passer de 100 variables à 2 ou 3 sans trop perdre d'information.

ACP · t-SNE · UMAP · Autoencodeurs

Pourquoi c'est difficile - le problème de l'évaluation

Sans labels, comment sait-on si le résultat est bon ?

En supervisé, on mesure P sur un jeu de test étiqueté. En non supervisé, il n'y a pas de "bonne réponse". On doit utiliser des critères internes (cohésion et séparation des clusters) ou une validation externe (expertise métier). C'est la principale difficulté du domaine.

Applications réelles

Segmentation clients
Grouper les clients par comportement d'achat pour personnaliser les offres marketing.
Détection d'anomalies
Identifier les transactions bancaires qui ne ressemblent à aucun groupe connu.
Compression d'images
Réduire le nombre de couleurs (K-Means) tout en préservant l'essentiel de l'image.
Bioinformatique
Regrouper des gènes à expression similaire pour découvrir des fonctions biologiques.
Visualisation
Projeter 1000 variables en 2D (ACP) pour explorer les données visuellement.
Recommandations
Trouver les utilisateurs similaires pour recommander des films ou des produits.
II Réduction de dimensionnalité

Analyse en Composantes Principales (ACP)

Section 02

ACP - Analyse en Composantes Principales

L'ACP cherche les directions de variance maximale dans les données. Ce sont les directions selon lesquelles les données "s'étalent" le plus. On projette ensuite les données sur ces directions pour obtenir une représentation compressée.

Intuition fondamentale

Imaginez un nuage de points en forme d'ellipse dans un espace 2D. La première composante principale (CP1) est l'axe le long duquel l'ellipse est la plus allongée - c'est la direction de variance maximale. La seconde composante (CP2) est perpendiculaire à CP1. En projetant les données sur CP1 seule, on passe de 2D à 1D en perdant le minimum d'information.

Algorithme mathématique

1
Centrer les données : soustraire la moyenne de chaque variable. Résultat : les données sont centrées sur l'origine.
2
Calculer la matrice de covariance : C = (1/n) · XᵀX. C est une matrice n×n (ou p×p si p variables) qui encode comment les variables varient ensemble.
3
Décomposition propre : trouver les vecteurs propres (v₁, v₂, …) et valeurs propres (λ₁, λ₂, …) de C. Les vecteurs propres sont les directions des composantes principales. Les valeurs propres mesurent la variance expliquée dans chaque direction.
4
Trier par variance décroissante : CP1 correspond à λ₁ (valeur propre maximale), CP2 à λ₂, etc.
5
Projeter : X_réduit = X · [v₁, v₂, …, vₖ]. On choisit k ≤ p composantes.
Formules clésMatrice de covariance : C = (1/n) · XᵀX (X est centré) Décomposition : C = V · Λ · Vᵀ V = matrice des vecteurs propres (les composantes) Λ = diag(λ₁, λ₂, …) avec λ₁ ≥ λ₂ ≥ … Variance expliquée par la CPᵢ : ratio = λᵢ / Σⱼ λⱼ ← entre 0 et 1 Projection sur k composantes : X_réduit = X · Vₖ où Vₖ contient les k premiers vecteurs propres

Cinq étudiants ont deux notes : Mathématiques et Physique. On applique l'ACP pour réduire à une seule dimension.

III Clustering

Méthodes de regroupement

Section 03

K-Means

K-Means est l'algorithme de clustering le plus simple et le plus utilisé. Il partitionne n points en K groupes de façon à minimiser la somme des distances au carré de chaque point à son centroïde (centre de son groupe).

Intuition

Imaginez K aimants posés dans l'espace. Chaque point de données est attiré par l'aimant le plus proche. Ensuite, chaque aimant se déplace vers le centre des points qui l'ont choisi. On répète jusqu'à ce que les aimants ne bougent plus.

Algorithme de Lloyd

1
Initialisation : placer K centroïdes μ₁, …, μₖ aléatoirement parmi les points de données (ou avec K-Means++ pour une meilleure initialisation).
2
Étape E (attribution) : assigner chaque point xᵢ au centroïde le plus proche. Cᵢ = argmin_k ||xᵢ − μₖ||²
3
Étape M (mise à jour) : recalculer chaque centroïde comme la moyenne des points qui lui sont assignés. μₖ = (1/|Cₖ|) · Σᵢ∈Cₖ xᵢ
4
Convergence : répéter les étapes 2 et 3 jusqu'à ce que les attributions ne changent plus (ou que la variation de l'inertie soit inférieure à ε).
Objectif - minimiser l'inertie intra-clusterJ = Σₖ Σᵢ∈Cₖ ||xᵢ − μₖ||² μₖ = centroïde du cluster k (moyenne des points assignés) |Cₖ| = nombre de points dans le cluster k L'algorithme décroît ou conserve J à chaque itération → Il converge toujours (mais vers un minimum local, pas forcément global)

Choisir K - la méthode du coude

K-Means nécessite de choisir K à l'avance. On trace l'inertie J en fonction de K. Elle décroît toujours (plus de clusters = moins de distance). On cherche le coude : le point où l'amélioration ralentit brusquement.

Limites de K-Means

K-Means suppose des clusters sphériques et de taille similaire. Il est sensible aux valeurs initiales des centroïdes (risque de minimum local). Section 04

CAH - Clustering Hiérarchique Agglomératif

La CAH construit une hiérarchie de clusters de bas en haut. On commence par traiter chaque point comme son propre cluster, puis on fusionne itérativement les deux clusters les plus proches jusqu'à n'en avoir plus qu'un seul.

Avantage clé sur K-Means

On n'a pas besoin de fixer K à l'avance. On construit l'arbre entier (le dendrogramme), puis on "coupe" à la hauteur souhaitée pour obtenir le nombre de clusters voulu. On peut changer K sans refaire le calcul.

Algorithme

1
Initialisation : chaque point est son propre cluster. On a n clusters au départ.
2
Calculer les distances : construire la matrice de distances inter-clusters D (n×n).
3
Fusionner : trouver les deux clusters i*, j* avec la plus petite distance. Les fusionner en un seul nouveau cluster C_{i*,j*}.
4
Mettre à jour D : calculer les distances entre le nouveau cluster et tous les autres (selon le critère de linkage choisi).
5
Répéter les étapes 3-4 jusqu'à avoir un seul cluster. Tracer le dendrogramme.

Critères de linkage - comment mesurer la distance entre clusters

Single linkage (lien minimum)
d(A,B) = min(d(a,b)) pour a∈A, b∈B
Distance = deux points les plus proches. Produit des clusters allongés ("chaining effect").
Complete linkage (lien maximum)
d(A,B) = max(d(a,b)) pour a∈A, b∈B
Distance = deux points les plus éloignés. Produit des clusters compacts et équilibrés.
Average linkage
d(A,B) = (1/|A||B|) Σᵢ∈A Σⱼ∈B d(i,j)
Moyenne de toutes les paires. Compromis entre single et complete.
Critère de Ward (recommandé)
ΔJ = (nAnB)/(nA+nB) · ||μA − μB||²
Minimise l'augmentation d'inertie lors de la fusion. Produit les clusters les plus compacts. Meilleur choix en général.

Exemple - dendrogramme sur 6 points

Lire le dendrogrammeLa hauteur d'une fusion indique la distance entre les deux clusters fusionnés. Pour obtenir K=2 : couper horizontalement à hauteur 4 → 2 clusters Pour obtenir K=3 : couper à hauteur 2.5 → 3 clusters Pour obtenir K=5 : couper à hauteur 1 → 5 clusters (presque un par point) On choisit la coupe là où il y a le plus grand saut vertical → K naturel des données.

Section 05

Mélange de Gaussiennes (GMM)

Le modèle de mélange de Gaussiennes suppose que les données sont générées par un mélange de K distributions gaussiennes. Chaque gaussienne représente un cluster potentiel. Contrairement à K-Means (affectations dures), les GMM donnent des probabilités d'appartenance (affectations douces).

K-Means vs GMM - la différence fondamentale

K-Means : chaque point appartient entièrement à un seul cluster (0 ou 1).
GMM : chaque point appartient partiellement à tous les clusters (probabilités qui somment à 1).
Ex : un point ambigu peut être à 70 % dans le cluster 1 et 30 % dans le cluster 2.

Modèle probabilisteP(x) = Σₖ πₖ · 𝒩(x | μₖ, Σₖ) πₖ = poids du cluster k (probabilité a priori d'appartenir à k) Σₖ πₖ = 1 μₖ = moyenne de la gaussienne k Σₖ = matrice de covariance de la gaussienne k (forme du cluster) Chaque point x vient du cluster k avec probabilité πₖ, puis est tiré selon la loi 𝒩(μₖ, Σₖ).

Algorithme EM (Expectation-Maximization)

E
Étape E (Expectation) - calculer les responsabilités :
rᵢₖ = P(cluster k | xᵢ) = πₖ · 𝒩(xᵢ | μₖ, Σₖ) / Σⱼ πⱼ · 𝒩(xᵢ | μⱼ, Σⱼ)
rᵢₖ est la "responsabilité" du cluster k pour le point i - sa probabilité d'appartenance.
M
Étape M (Maximization) - mettre à jour les paramètres :
Nₖ = Σᵢ rᵢₖ (effectif effectif du cluster k)
πₖ = Nₖ / n | μₖ = (1/Nₖ) Σᵢ rᵢₖ xᵢ | Σₖ = (1/Nₖ) Σᵢ rᵢₖ (xᵢ−μₖ)(xᵢ−μₖ)ᵀ
⟳
Répéter E → M jusqu'à convergence de la vraisemblance log-L = Σᵢ log P(xᵢ). L'EM garantit que L croît ou reste constante à chaque itération.
Choisir K pour les GMM

On utilise le BIC (Bayesian Information Criterion) ou l'AIC (Akaike Information Criterion). Ces critères pénalisent la complexité du modèle pour éviter l'overfitting. On choisit K qui minimise BIC ou AIC.

BIC et AIC - critères de sélection de KBIC = −2 · log-L + p · log(n) ← pénalité plus forte (préfère K plus petit) AIC = −2 · log-L + 2 · p ← pénalité plus faible (plus de clusters tolérés) p = nombre de paramètres libres du modèle = K·d (moyennes) + K·d(d+1)/2 (covariances) + K−1 (poids) où d = dimension de l'espace → On trace BIC/AIC vs K et on choisit le coude minimum
Avantages des GMM
Clusters elliptiques (pas seulement sphériques) · Affectations probabilistes · Modèle génératif · BIC/AIC pour choisir K
Inconvénients des GMM
Suppose des données gaussiennes · Sensible aux valeurs initiales · Plus lent que K-Means · Peut diverger (covariances singulières)
Section 06

DBSCAN

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) trouve des clusters basés sur la densité, pas sur la distance à un centroïde. Il peut détecter des clusters de forme arbitraire et identifie automatiquement les points aberrants (bruit).

Intuition - définir un cluster par la densité

Un cluster est une zone dense de points, séparée de zones moins denses. Un point isolé au milieu d'une zone vide est du bruit (pas dans un cluster). DBSCAN n'a pas besoin de connaître K - il le découvre automatiquement.

Deux paramètres clés

ε (epsilon) - rayon de voisinage
Le voisinage d'un point x est la boule de rayon ε centrée en x. Tous les points à distance ≤ ε de x en font partie.
minPts - seuil de densité
Nombre minimum de points requis dans le voisinage ε pour qu'un point soit considéré "dense" (point cœur).

Classification des points

Trois types de points dans DBSCANPoint cœur (core) : |N_ε(x)| ≥ minPts Son voisinage ε contient au moins minPts points (lui inclus) → Il est au cœur d'une zone dense Point bord (border) : |N_ε(x)| < minPts et x est dans N_ε(d'un point cœur) Pas assez de voisins pour être cœur, mais est voisin d'un cœur → Il est à la frontière d'un cluster Bruit (noise/outlier) : ni cœur, ni bord Isolé, pas dans le voisinage d'aucun point cœur → Rejeté comme anomalie (label = −1)

Algorithme

1
Pour chaque point non visité, calculer son voisinage N_ε(x).
2
Si |N_ε(x)| ≥ minPts : créer un nouveau cluster. Étendre le cluster en ajoutant récursivement tous les points accessibles par densité depuis x.
3
Si |N_ε(x)| < minPts : marquer x comme bruit provisoirement. Il pourra être récupéré comme point bord si un cluster voisin l'atteint.
4
Répéter pour tous les points non visités.

Évaluer un clustering sans labels

Sans vérité terrain (labels), l'évaluation repose sur des critères internes qui mesurent la qualité de la structure découverte : cohésion intra-cluster et séparation inter-clusters.

Inertie intra-cluster (WCSS)
J = Σₖ Σᵢ∈Cₖ ||xᵢ − μₖ||²
Somme des distances au carré au centroïde. Mesure la cohésion. Plus petit = mieux. Utilisé pour la méthode du coude.
Score de silhouette
s(i) = (b(i)−a(i)) / max(a(i),b(i))
a(i) = distance moyenne intra-cluster · b(i) = distance moyenne au cluster voisin le plus proche. s ∈ [−1, 1], proche de 1 = bien groupé.
Indice de Davies-Bouldin
DB = (1/K)Σₖ max_{j≠k}(σₖ+σⱼ)/d(μₖ,μⱼ)
σₖ = dispersion du cluster k. d(μₖ,μⱼ) = distance entre centroïdes. Plus petit = mieux (0 est parfait).
Interprétation du score de silhouettes(i) proche de +1 → le point est bien placé dans son cluster, loin des autres s(i) proche de 0 → le point est à la frontière entre deux clusters s(i) proche de −1 → le point est probablement dans le mauvais cluster Silhouette moyenne sur tous les points → qualité globale du clustering On trace le silhouette plot (un bar par point, trié) pour diagnostiquer la qualité.

Âge · Revenu annuel (k$) · Score de dépense (1-100)
Objectif
Trouver les segments naturels pour adapter les campagnes
Plan du TP - 6 partiesPartie 1 : Chargement et exploration des données (EDA) Partie 2 : Standardisation et ACP (réduction à 2D pour visualisation) Partie 3 : K-Means - méthode du coude et score de silhouette Partie 4 : DBSCAN - détection d'anomalies Partie 5 : GMM - affectations probabilistes et BIC Partie 6 : Comparaison, interprétation et recommandations marketing
